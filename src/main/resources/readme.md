# Transactions App
Read | Write | Sort | Filter

## Screens
<details> 
<summary> Home... </summary>

## You are presented with 3 Options
Type the letter of the action you want ot take and hit enter00
***


D) Add to Deposit

P) Make a Payment

<details>
<summary> Making a Transaction </summary>

You will be prompted a series of 5 questions which will result in adding the transaction to the CSV 
</details>

L) Switch to the Ledger screen
</details>
<details> 
<summary> Ledger... </summary>

## You are presented with 4 options
Every display will be sorted by date (newest first), and will include newly logged transactions
***


A) Display all entries 

D) Display all deposits

P) Displaying all payments

R) Switch to the reports screen
</details>
<details> 
<summary> Reports... </summary>

## You are presented with 7 options
There are 4 preset filters to quickly grab any common searches for transactions
***

1. Month To Date - Prints all results within the current MONTH
2. Previous Month
3. Year To Date 
4. Previous Year
5. Search by Vendor 
6. Custom Search - For more specific results, you will be prompted for every identifier in a transaction <br>
Entries can be left blank and ALL results will be wrote to a new csv file labeled customSearch# <-depnding on how many custom searches are made


B) Back to Home
</details>
